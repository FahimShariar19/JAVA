01

Bold & Italic — <b> <strong> <i> <em>

কী করে?

Bold মানে লেখাকে মোটা করা। Italic মানে লেখাকে বাঁকানো। এগুলো দিয়ে আমরা গুরুত্বপূর্ণ শব্দ হাইলাইট করি।

বইয়ে যেমন গুরুত্বপূর্ণ কথা underline বা bold করা থাকে — HTML-এ সেটাই করি <strong> দিয়ে। আর বইয়ে বিদেশী শব্দ বা বিশেষ term italic হয় — সেটাই <em> দিয়ে।
⚠️ পার্থক্য জানো

<b> শুধু দেখতে bold করে (visual only)। কিন্তু <strong> দিয়ে browser-কে বলি "এটা semantically important" — screen reader-রাও বোঝে।
একইভাবে <i> শুধু visual italic, কিন্তু <em> মানে "emphasis" বা জোর দেওয়া।

HTML 
<!-- Bold -->
<b>এটা শুধু bold দেখাবে</b>
<strong>এটা bold + গুরুত্বপূর্ণ</strong>

<!-- Italic -->
<i>এটা শুধু italic দেখাবে</i>
<em>এটা italic + emphasized</em>

<!-- একসাথেও ব্যবহার করা যায় -->
<strong><em>Bold এবং Italic একসাথে!</em></strong>
LIVE OUTPUT
এটা শুধু bold দেখাবে
এটা bold + গুরুত্বপূর্ণ
এটা শুধু italic দেখাবে
এটা italic + emphasized
Bold এবং Italic একসাথে!
02

Underline — <u>

কী করে?

লেখার নিচে একটা দাগ টেনে দেয়। সাধারণত spelling error বা proper noun বোঝাতে ব্যবহার হয়।

পরীক্ষার খাতায় উত্তরের নিচে দাগ টানলে যেরকম দেখায় — HTML-এ <u> ঠিক সেটাই করে।
HTML 
<p>আমার প্রিয় বিষয় হলো <u>HTML</u>।</p>

<p>এই শব্দটার বানান ভুল: <u>recieve</u></p>
LIVE OUTPUT

আমার প্রিয় বিষয় হলো HTML।

এই শব্দটার বানান ভুল: recieve

03

Subscript & Superscript — <sub> <sup>

কী করে?

Subscript (<sub>): লেখাকে নিচে ছোট করে — যেমন রসায়নের সূত্রে H₂O।
Superscript (<sup>): লেখাকে উপরে ছোট করে — যেমন গণিতে x²।

বিজ্ঞান বইয়ে H₂O লেখার সময় "2" টা ছোট করে নিচে থাকে — সেটাই subscript। আর 10² লেখার সময় "2" উপরে ছোট থাকে — সেটাই superscript।
HTML 
<!-- Subscript - Chemistry -->
<p>পানির সূত্র: H<sub>2</sub>O</p>
<p>CO<sub>2</sub> = কার্বন ডাই অক্সাইড</p>

<!-- Superscript - Math -->
<p>2 এর ঘন = 2<sup>3</sup> = 8</p>
<p>এটা 10<sup>th</sup> anniversary!</p>
LIVE OUTPUT

পানির সূত্র: H2O

CO2 = কার্বন ডাই অক্সাইড

2 এর ঘন = 23 = 8

এটা 10th anniversary!

04

Image — <img>

কী করে?

Webpage-এ ছবি দেখায়। এটা একটা self-closing tag — মানে এর কোনো closing tag নেই (</img> লাগে না)।

যেমন একটা ফ্রেমে ছবি লাগানো হয় — <img> ট্যাগটা সেই ফ্রেম, আর src attribute হলো ছবির ঠিকানা।
Attributeকী করে
srcছবির ঠিকানা (URL বা file path)
altছবি না দেখালে এই লেখা দেখাবে (accessibility-র জন্য জরুরি)
widthছবির প্রস্থ (pixel বা %)
heightছবির উচ্চতা (pixel বা %)
HTML 
<!-- Basic image -->
<img src="cat.jpg" alt="একটা বিড়ালের ছবি">

<!-- Size দিয়ে -->
<img src="logo.png" alt="Company Logo"
     width="200" height="100">

<!-- Online URL থেকে ছবি -->
<img
  src="https://picsum.photos/300/150"
  alt="Random photo"
  width="300"
>
LIVE OUTPUT
↑ Online URL থেকে লোড হওয়া ছবি
05

Hyperlink — <a>

কী করে?

একটা page থেকে অন্য page-এ যাওয়ার link তৈরি করে। <a> মানে "anchor" — মানে কোথাও "নোঙর" ফেলা।

যেমন একটা বইয়ে "পৃষ্ঠা ৪৫ দেখুন" লেখা থাকে — সেটা একটা reference। HTML-এ hyperlink ঠিক তেমনই, কিন্তু click করলেই সেখানে চলে যাবে!
Attributeকী করে
hrefকোথায় যাবে — URL বা file path
target="_blank"নতুন tab-এ খুলবে
target="_self"একই tab-এ খুলবে (default)
href="mailto:..."Email পাঠানোর link
href="tel:..."Phone call link (mobile-এ)
HTML 
<!-- সাধারণ link -->
<a href="https://google.com">Google-এ যাও</a>

<!-- নতুন tab-এ খুলবে -->
<a href="https://youtube.com" target="_blank">
  YouTube (নতুন tab)
</a>

<!-- Email link -->
<a href="mailto:info@example.com">
  আমাকে email করুন
</a>

<!-- Phone link -->
<a href="tel:+8801700000000">
  Call করুন
</a>

<!-- Image-এ link দেওয়া যায়! -->
<a href="https://google.com">
  <img src="logo.png" alt="Logo">
</a>
LIVE OUTPUT
Google-এ যাও

YouTube (নতুন tab)

আমাকে email করুন

Call করুন
06

Lists — <ul> <ol> <li>

কী করে?

Unordered List (<ul>): bullet point সহ তালিকা — যেখানে ক্রম গুরুত্বপূর্ণ না।
Ordered List (<ol>): নম্বর সহ তালিকা — যেখানে ক্রম গুরুত্বপূর্ণ।
List Item (<li>): তালিকার প্রতিটি আইটেম।

বাজারের list (আলু, পেঁয়াজ, রসুন) — এখানে কোনটা আগে কিনবে সেটা গুরুত্বপূর্ণ না, তাই <ul>। কিন্তু রান্নার ধাপ (প্রথমে তেল গরম করো, তারপর পেঁয়াজ দাও...) — এখানে ক্রম জরুরি, তাই <ol>।
HTML 
<!-- Unordered List (bullet points) -->
<ul>
  <li>আলু</li>
  <li>পেঁয়াজ</li>
  <li>রসুন</li>
</ul>

<!-- Ordered List (numbered) -->
<ol>
  <li>তেল গরম করো</li>
  <li>পেঁয়াজ দাও</li>
  <li>মশলা দিয়ে রান্না করো</li>
</ol>

<!-- Nested List (list-এর ভেতরে list) -->
<ul>
  <li>ফল
    <ul>
      <li>আম</li>
      <li>কলা</li>
    </ul>
  </li>
  <li>সবজি</li>
</ul>
LIVE OUTPUT
Unordered:
  • আলু
  • পেঁয়াজ
  • রসুন
Ordered:
  1. তেল গরম করো
  2. পেঁয়াজ দাও
  3. রান্না করো
Nested:
  • ফল
    • আম
    • কলা
  • সবজি
07

Table — <table> এবং সব attributes

Table-এর Structure

<table> — পুরো টেবিল
<tr> — Table Row (একটা সারি)
<th> — Table Header (heading cell — bold হয়)
<td> — Table Data (সাধারণ cell)

একটা Excel spreadsheet কল্পনা করো। প্রতিটা row হলো <tr>, প্রতিটা cell হলো <td>, আর header row-এর cell গুলো <th>।
7.1 — Basic Table

সবচেয়ে সাধারণ টেবিল — row এবং column।

Basic Table 
<table border="1">
  <tr>
    <th>নাম</th>
    <th>বয়স</th>
    <th>শহর</th>
  </tr>
  <tr>
    <td>রাহেলা</td>
    <td>22</td>
    <td>ঢাকা</td>
  </tr>
  <tr>
    <td>করিম</td>
    <td>25</td>
    <td>চট্টগ্রাম</td>
  </tr>
</table>
LIVE OUTPUT — Basic Table
নামবয়সশহর
রাহেলা22ঢাকা
করিম25চট্টগ্রাম
7.2 — colspan (একাধিক column জুড়ে দেওয়া)

colspan="2" মানে এই cell টি 2টি column জুড়ে বিস্তৃত হবে।

যেমন একটা ঘরের দেওয়াল ভেঙে দুটো ঘর এক করা — colspan সেটাই করে, দুটো cell কে জোড়া লাগায় পাশাপাশি।
colspan Example 
<table border="1">
  <tr>
    <!-- এই th দুটো column দখল করবে -->
    <th colspan="2">ব্যক্তিগত তথ্য</th>
    <th>নম্বর</th>
  </tr>
  <tr>
    <td>নাম</td>
    <td>বয়স</td>
    <td>ফোন</td>
  </tr>
  <tr>
    <td>আরিফ</td>
    <td>20</td>
    <td>01700000</td>
  </tr>
</table>
LIVE OUTPUT — colspan
ব্যক্তিগত তথ্যনম্বর
নামবয়সফোন
আরিফ2001700000
7.3 — rowspan (একাধিক row জুড়ে দেওয়া)

rowspan="2" মানে এই cell টি 2টি row জুড়ে নিচে বিস্তৃত হবে।

উপরে-নিচে দুটো ঘর ভেঙে একটা লম্বা ঘর বানানো — rowspan সেটাই করে, উপর-নিচে দুটো cell জোড়া লাগায়।
rowspan Example 
<table border="1">
  <tr>
    <!-- এই td দুটো row দখল করবে -->
    <td rowspan="2">বিজ্ঞান</td>
    <td>পদার্থবিদ্যা</td>
    <td>৮৫</td>
  </tr>
  <tr>
    <!-- এখানে প্রথম td দরকার নেই, rowspan নিয়েছে -->
    <td>রসায়ন</td>
    <td>৯০</td>
  </tr>
  <tr>
    <td>গণিত</td>
    <td>বীজগণিত</td>
    <td>৯৫</td>
  </tr>
</table>
LIVE OUTPUT — rowspan
বিভাগবিষয়নম্বর
বিজ্ঞানপদার্থবিদ্যা৮৫
রসায়ন৯০
গণিতবীজগণিত৯৫
7.4 — cellpadding এবং align

cellpadding: cell-এর ভেতরে content-এর চারপাশে কতটুকু জায়গা থাকবে (padding)।
align: text কোন দিকে থাকবে — left, center, right।

cellpadding হলো একটা বাক্সের ভেতরে জিনিসের চারপাশের foam। আর align হলো বাক্সের ভেতরে জিনিসটা বাম দিকে, মাঝে, না ডান দিকে রাখব।
cellpadding + align 
<table border="1" cellpadding="12" align="center">
  <tr>
    <th align="left">পণ্য</th>
    <th align="center">পরিমাণ</th>
    <th align="right">দাম (৳)</th>
  </tr>
  <tr>
    <td align="left">চাল</td>
    <td align="center">5 kg</td>
    <td align="right">350</td>
  </tr>
  <tr>
    <td align="left">ডাল</td>
    <td align="center">2 kg</td>
    <td align="right">180</td>
  </tr>
</table>
LIVE OUTPUT — cellpadding + align
পণ্য পরিমাণ দাম (৳)
চাল 5 kg 350
ডাল 2 kg 180
