# 🤝 Contributing to JAVA Lab Resources

Thank you for considering contributing to this repository! Whether you are a classmate looking to fix an issue, add a new lab solution, or optimise existing Java code, your help is warmly appreciated.

---

## 🚀 How to Contribute

### 1. Fork the Repository
Click the **Fork** button at the top right of this page to create a copy of this repository under your own GitHub account.

### 2. Clone Your Fork
Open your terminal or Git Bash and clone your fork to your local machine:
```bash
git clone https://github.com/FahimShariar19/JAVA.git
```

### 3. Create a New Branch
Create a descriptive branch name for your changes:
```bash
git checkout -b fix/lab-issue-or-feature
```

### 4. Make Your Changes & Test
Add or fix the code in the appropriate folder. Ensure code follows standard Java formatting and compiles cleanly without errors:
```bash
javac FileName.java
```

### 5. Commit Your Changes
Write a clear commit message:
```bash
git commit -m "Fix: Corrected loop logic in Lab 03"
```

### 6. Push and Create a Pull Request (PR)
Push your branch to GitHub:
```bash
git push origin fix/lab-issue-or-feature
```

Then, open a **Pull Request** on the original repository describing the changes you made!

---

## 💡 Guidelines
* Keep the code clean and properly commented where necessary.
* Avoid uploading compiled `.class` files.
